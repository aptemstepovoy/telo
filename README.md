# Тело — дневник тренировок и питания

Простой персональный фитнес-дневник как **веб-приложение (PWA)**: ставится на домашний экран
телефона, работает офлайн, данные хранятся только на устройстве. Никакого сервера и аккаунтов.

**Круг:** Клод даёт план недели в JSON → загружаешь в приложение → всю неделю отмечаешь факт
по подходам + утренний вес и талию → в конце недели выгружаешь JSON обратно Клоду → он планирует
следующую неделю. И так по кругу.

## Возможности

- **Сегодня** — тренировка дня: план по каждому упражнению (подходы/повторы/вес/RPE/TUT/отдых),
  поля для факта по каждому подходу. Утренний вес и талия сверху. Подсказка «прошлый раз»
  с прошлыми цифрами по этому упражнению (прогрессия).
- **Управляемый подход** — кнопка ▶: отсчёт «Приготовься» → таймер «Под нагрузкой» (TUT) с
  громким сигналом «стоп» → кнопка «Готово» → автоматически таймер отдыха (между подходами, а
  после последнего — между упражнениями). Экран не гаснет (Wake Lock), показ на экране
  блокировки (Media Session), «режим будильника» перебивает музыку. Звук и вибрация.
- **Заметки дня** — внизу «Сегодня» свободное поле: как прошла тренировка, что по питанию.
  Уходит в экспорт Клоду для разбора.
- **Неделя** — все 7 дней с прогрессом выполнения, **список покупок** (чек-лист) и компактные
  графики веса/талии с целевой линией.
- **Данные** — импорт/экспорт JSON (файл или буфер), настройки, кнопка
  «Скопировать инструкцию для Клода».

## Запуск локально

Любой статический сервер. Например:

```bash
# из папки telo/
python -m http.server 8000
# открыть http://localhost:8000
```

> Открывать просто файлом (`file://`) не стоит: не заработают `fetch` примера и service worker.
> Нужен http(s).

## Деплой на GitHub Pages

1. Создай репозиторий и залей содержимое этой папки в корень:
   ```bash
   git init
   git add .
   git commit -m "Тело — дневник"
   git branch -M main
   git remote add origin https://github.com/<ты>/<репо>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)`. Сохрани.
3. Через минуту приложение будет на `https://<ты>.github.io/<репо>/`.
   Пути в проекте относительные — работает в подпапке без правок.

### На свой сервер
Просто положи файлы в любую папку под HTTPS-доменом и открой `index.html`. HTTPS обязателен
для установки на домашний экран и офлайна.

## Установить на телефон

- **Android (Chrome):** меню ⋮ → «Установить приложение» (или баннер). Иконка появится на экране.
- **iOS (Safari):** «Поделиться» → «На экран Домой».

## Иконки

Сгенерированы из `icon.svg` скриптом без зависимостей:

```bash
node tools/gen-icons.mjs
```

## Структура

```
index.html             разметка-оболочка
styles.css             тёмная мобильная тема
app.js                 вся логика (состояние, импорт/экспорт, экраны, графики, таймер)
manifest.webmanifest   PWA-манифест
sw.js                  service worker (офлайн-кэш)
icon.svg               исходная иконка
icons/                 PNG-иконки (сгенерированы)
sample-week.json       пример плана (кнопка «Пример»)
CLAUDE_PLAN_FORMAT.md  контракт обмена с Клодом
tools/gen-icons.mjs    генератор иконок
```

Формат обмена с Клодом — см. [CLAUDE_PLAN_FORMAT.md](CLAUDE_PLAN_FORMAT.md).
Данные хранятся в `localStorage` — для бэкапа есть «Резервная копия (все недели)».
