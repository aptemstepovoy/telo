# Формат обмена с Клодом (проект «тело»)

Это контракт между Клодом и приложением-дневником. Один файл = одна неделя.

В приложении на вкладке **Данные → «Скопировать инструкцию для Клода»** лежит готовый текст —
вставь его один раз в проект «тело», и Клод будет выдавать план сразу в этом формате.

## Как работает круг

1. Просишь у Клода план на неделю → он отдаёт **JSON** (блок кода).
2. Копируешь JSON → в приложении **Данные → Из файла / Вставить** загружаешь.
3. Всю неделю на вкладке **Сегодня** отмечаешь факт по подходам + утренний вес и талию.
4. В конце недели **Данные → Скачать неделю** (или «Скопировать»).
5. Отдаёшь этот JSON Клоду → он анализирует факт vs план и выдаёт новую неделю. Повтор.

## Структура

```json
{
  "schema": "fitness-diary",
  "version": 1,
  "week": {
    "label": "Неделя 1",
    "startDate": "2026-06-01",
    "goal": "Дефицит ~500 ккал, белок 2 г/кг"
  },
  "athlete": {
    "targets": { "weightKg": 90, "waistCm": 85 }
  },
  "days": [
    {
      "date": "2026-06-01",
      "training": {
        "title": "Грудь + трицепс",
        "isRestDay": false,
        "notes": "разминка 10 мин",
        "exercises": [
          {
            "name": "Жим штанги лёжа",
            "targetSets": 4,
            "targetReps": "8-10",
            "targetWeight": 60,
            "targetRpe": 8,
            "tut": 40,
            "rest": 120,
            "restAfter": 180,
            "notes": ""
          }
        ]
      },
      "nutrition": {
        "title": "2200 ккал",
        "summary": { "kcal": 2200, "protein": 180, "carbs": 200, "fat": 60 },
        "meals": [
          { "name": "Завтрак", "items": ["Овсянка 80 г", "Яйца 3 шт"], "kcal": 550 }
        ],
        "notes": ""
      }
    }
  ],
  "shopping": [
    { "category": "Белок", "items": ["Куриная грудка 1.5 кг", "Яйца 30 шт"] },
    { "category": "Крупы", "items": ["Овсянка 1 кг", "Рис 1 кг"] }
  ]
}
```

## Поля

| Поле | Тип | Описание |
|---|---|---|
| `week.startDate` | строка `ГГГГ-ММ-ДД` | Понедельник недели. Обязательно. |
| `week.label` / `week.goal` | строка | Название и цель недели (необязательно). |
| `athlete.targets.weightKg` / `waistCm` | число | Целевые значения — рисуются пунктиром на графиках. |
| `days[]` | массив | Обычно 7 дней, даты подряд от `startDate`. |
| `days[].date` | строка `ГГГГ-ММ-ДД` | Дата дня. |
| `training.title` | строка | Заголовок тренировки. |
| `training.isRestDay` | bool | День отдыха → `exercises` пустой. |
| `training.exercises[].name` | строка | Название упражнения. |
| `targetSets` | число | План подходов (создаст столько пустых строк для факта). |
| `targetReps` | строка | План повторов: `"8-10"` или `"12"`. |
| `targetWeight` | число / null | План веса, кг. |
| `targetRpe` | число / null | Целевой RPE (1–10). |
| `tut` | число / null | Время под нагрузкой, сек/подход (для таймера «под нагрузкой»). |
| `rest` | число / null | Отдых **между подходами**, сек. |
| `restAfter` | число / null | Отдых **между упражнениями**, сек (после последнего подхода). |
| `tempo` | строка / null | Темп, напр. «3-1-1» (показывается, не таймерится). |
| `nutrition.summary` | объект / null | КБЖУ дня (можно опускать). |
| `nutrition.meals[]` | массив | Приёмы: `name`, `items[]`, `kcal`. |
| `shopping` | массив | Список покупок на неделю. Группы `{category, items[]}` или просто массив строк. |

## Что заполняет приложение (Клод НЕ трогает)

- `days[].training.exercises[].sets[]` — факт: `{ "reps", "weight", "rpe", "done" }` по каждому подходу.
- `days[].body` — утренние замеры: `{ "weightKg", "waistCm" }`.
- `trends[]` — динамика веса/талии по датам (приложение добавляет в экспорт автоматически,
  чтобы Клод видел тренд; при импорте — наполняет графики, даже на новом устройстве).

Питание в приложении — **только просмотр** (без отметок), это осознанный выбор простоты.
